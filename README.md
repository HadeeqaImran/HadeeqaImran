## How I think about engineering

### 01. Product first

Good engineering is not only about clean code. It is about understanding the workflow, finding the real constraint, and shipping something that makes the user's job easier.

### 02. Production changes the problem

A feature that works locally is only the beginning. I care about performance, edge cases, observability, error states, maintainability, and what happens after release.

### 03. AI should earn its place

I am most interested in AI when it improves a real workflow: retrieval, decision support, automation, generation, personalization, or turning unstructured information into something useful.

### 04. Own the full path

I like being able to move from interface details to API design, data modeling, integrations, analytics, and deployment without losing sight of the product as a whole.
